# 青空之下（Under the Blue Sky）

一个纯前端、单文件的日式校园恋爱模拟游戏（galgame）。

## 玩法

- **创建角色**：名字 → 性别 → 天赋抽取（每轮刷 3 位同学、各选 1 项属性继承，共 14 项）
- **高中三年 = 72 周**，每周 3 个行动点（学习 / 锻炼 / 社交 / 约会等）
- **20 位同学**：4 位可攻略女主（李静 / 利普 / 王雯 / 珂珂）+ 4 位男主（田嘉 / 秦阳 / 张玄 / 福克斯），其余为挚友线
- **丰富的选择事件与连锁剧情**，属性与好感共同驱动走向
- **多结局**：恋爱 / 挚友 / 学业

## 运行

直接用浏览器打开 `index.html` 即可，无需服务器。

## 技术

- 纯 HTML / CSS / JS，无框架，移动端自适应
- 立绘为代码生成的 SVG 手绘
- 背景图位于 `bg/` 目录

## 测试

```bash
node smoke_test.js   # 冒烟测试
node playtest.js     # 深度试玩模拟
```
